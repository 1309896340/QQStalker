## Purpose

为大模型返回的 JSON 响应建立统一的本地校验与重试契约：只有通过结构校验的响应才能进入后续步骤，非法响应通过纠错反馈重试修复，最终失败时被隔离降级，避免非法结果被当作正确结果传播引发连锁报错。

## Requirements

### Requirement: JSON 响应的结构校验与纠错重试

凡以 JSON 对象为输出约定的大模型请求阶段，系统 SHALL 在本地对响应完成 JSON 解析与结构校验：响应必须可解析为 JSON 对象，且满足该阶段约定的必填字段、字段类型与取值约束（如整数行号、布尔判定、区间完整覆盖）。校验失败（包括 JSON 解析失败）的响应 MUST NOT 被当作有效结果进入任何后续处理。

校验失败时，系统 SHALL 携带校验错误文本作为纠错反馈自动重试，反馈 MUST 说明失败原因并要求模型严格按原始要求重新完整输出；重试仍失败时 SHALL 继续重试直至达到该阶段的尝试总次数上界。同一请求的重试（含首次）总次数上界 SHALL 由系统统一定义，不因阶段而异；纠错反馈 prompt MUST 与原始 prompt 构成不同的缓存键，使重试不受被拒响应的缓存条目影响。

全部重试失败时，系统 SHALL 按该阶段的既有降级行为处理，并 SHALL 保留包含完整请求内容、模型原始响应与校验错误的拒答记录以供排查。

#### Scenario: 非法 JSON 触发纠错重试并成功

- **WHEN** 模型返回的响应中字符串字段缺少引号导致 JSON 解析失败
- **THEN** 系统拒绝该响应，携带校验错误作为反馈自动重试，重试响应通过校验后按正常流程继续，首次的非法响应不进入任何后续步骤

#### Scenario: 反馈重试不受投毒缓存影响

- **WHEN** 首次响应未通过校验且该响应已存在缓存条目，系统发起纠错反馈重试
- **THEN** 重试请求使用与原始 prompt 不同的缓存键，命中其自身的缓存结果或正常发起网络请求，MUST NOT 返回已被拒绝的首次响应

#### Scenario: 重试上界

- **WHEN** 同一请求的响应连续多次未通过校验，达到系统定义的重试总次数上界
- **THEN** 系统停止重试，按该阶段的降级行为处理，并写入包含校验错误的拒答记录，不向上抛出未处理异常中断整体分析

### Requirement: 非法响应不得进入后续请求

阶段校验失败产生的降级产物（如未识别片段候选、降级纪要）MUST NOT 把被拒绝的原始响应文本或校验错误文本注入后续大模型请求的输入中；降级产物 SHALL 仅携带语义中立的占位说明（如"该段消息未能完成议题识别"），使后续归并与纪要请求不因前序失败内容产生连锁校验失败。

#### Scenario: 跳过分段不污染归并请求

- **WHEN** 某分段经全部重试仍未通过 JSON 校验，其降级候选进入议题归并请求
- **THEN** 归并请求输入中只包含该候选的语义中立占位说明，不包含被拒绝的原始响应文本或校验错误文本，归并请求本身正常完成校验
