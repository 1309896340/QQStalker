## Context

纪要由 LLM 生成后，`bold_member_names` 用最长优先裸子串匹配把可信名单中的名字包成 `**名字**`，前端按 strong 文本在 `member_styles`（以完整群名片为键）中精确查找上色。模型撰写时会把完整群名片缩写（`祥子(ut 不重要了健康才重要）` → `祥子`），匹配不到全名导致漏高亮；反过来短英文名 `nt` 会命中 `break`/`continue` 内部导致误高亮。主规格要求高亮由系统对照可信名单确定性完成，不执行模型输出的标记。

## Goals / Non-Goals

**Goals:**

- 纪要中的成员提及（含模型缩写）尽可能被高亮，且同一成员颜色全局一致。
- 消除英文单词内部的误高亮。
- 保持既有安全约束：高亮结果仅由系统对照可信名单确定性产生。

**Non-Goals:**

- 不做通用别名/昵称库或模糊匹配（如“某某哥”类变体）。
- 不改变纪要内容生成、字数校验、重试与降级逻辑。
- 不改动热度图配色与图表渲染。

## Decisions

- **模型侧：逐字署名 + 纯文本标记。** `_minutes_instruction` 增加两条要求：提及成员必须逐字使用消息行署名中的完整群名片；可用 `<<完整署名>>` 标注。选择纯文本标记而非让模型直接输出 `**`：`_normalize_minutes_text` 会剥掉 `**`，模型直接输出的加粗不可靠；`<<>>` 是普通文本，能穿过现有归一化，由系统在校验后统一转换。备选“完全不让模型参与标注、只靠本地匹配”实现最简单，但无法覆盖模型自由发挥的变体，漏高亮率明显更高。
- **标记校验放在高亮层而非归一化层。** 在 `with_member_highlights`/`bold_member_names` 一侧处理：`<<name>>` 仅当 name 与可信名单（含别名）精确匹配时替换为 `**name**`，否则剥壳保留文字。理由：归一化层拿不到 roster，且所有高亮决策集中在一处便于测试与保证确定性；校验失败选择剥壳降级而非重试，沿用“确定性修复而非拒绝”的既有取向，重试一个 200~300 字自然段的边际收益低。
- **词边界只约束含 ASCII 字母/数字的名字。** 对这类名字使用 `(?<![A-Za-z0-9])名字(?![A-Za-z0-9])`；纯中文名维持裸子串（中文无可靠词边界，且中文名误命中概率低）。实现上为每个名字生成带条件的 pattern，按长度降序合并为单个交替表达式，保证 `祥子(ut…）` 优先于别名 `祥子` 命中。
- **别名派生规则从简。** 取第一个 `(` 或 `（` 之前的非空主干作为别名；别名仅在其与所有其他成员的规范名、已派生别名都不冲突时启用。颜色映射扩展为别名 → 规范名颜色（`member_styles` 同时包含规范名与别名两个键，指向同一色值），前端无需改动。
- **`appeared` 判定同步覆盖别名。** `with_member_highlights` 收集出现成员时，别名命中即视为该规范名出现，保证只出现别名的议题也能拿到配色。

## Risks / Trade-offs

- [模型不按要求使用完整署名或标记] → 别名派生兜住最常见的“括号备注缩写”；未命中处只是不高亮，不影响内容正确性。
- [别名主干过短（如单字名）或与其他成员冲突] → 冲突即放弃别名；单字别名风险低（中文子串匹配本就按名字命中）。
- [标记剥壳后正文残留书名号样式的 `<>` 符号] → 剥壳仅移除成对的 `<<`、`>>`，正文文字保留，视觉上无残留。
- [含 ASCII 名字在中文语境紧邻中文时（如“nt说”）] → 词边界只排除 ASCII 字母数字相邻，中文相邻仍命中，符合预期。

## Migration Plan

单次代码变更，无数据迁移；重新生成报告即生效。回滚即还原该次提交。
